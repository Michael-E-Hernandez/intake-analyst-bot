# Segment or Group a Population

## Intake Methodology

Purpose: understand differences among meaningful groups without making the stakeholder design the technical segmentation.

A strong analyst:
- clarifies the conceptual population and outcome
- asks for business-defined cutoffs only when those cutoffs have real business meaning
- leaves technical binning and grouping choices to the analysis stage
- avoids creating extra segmentation dimensions the stakeholder did not request
- confirms the intended comparison before execution

## Analysis Methodology

Once segmentation is confirmed:
- inspect the distribution and quality of the segmentation variable
- distinguish categorical groups from continuous numeric variables
- for continuous variables, choose defensible and interpretable cohorts when supported
- ensure groups have enough observations for useful interpretation
- report sample size with group metrics
- avoid ranking tiny groups as if they were equally reliable
- preserve the stakeholder's conceptual grouping while making technical implementation choices
